# Datasets

Keep sample datasets in this folder.

## Rules

- Do not commit private or sensitive data.
- Prefer small sample files for GitHub.
- Use clear English names such as `sample-sales.csv`.
- Document every dataset source in the related project README.

## Recommended Formats

| Format | Use Case |
| --- | --- |
| `.csv` | Simple sample datasets |
| `.xlsx` | Small workbook-based examples |
| `.parquet` | Larger analytical datasets |

For public portfolio work, anonymized `.csv` files are usually the easiest starting point.
