# Power BI Documentation

This folder contains the conceptual learning notes for Power BI.

The writing style follows a practical learning flow:

1. Explain the concept shortly.
2. Show why it matters.
3. Connect it to a real reporting scenario.
4. Add warnings where mistakes are common.
5. Continue from simple examples to more professional usage.
