# Report Design

Report design is not decoration. It is the process of helping the reader understand the data quickly and correctly.

## First Question

Before adding visuals, ask:

> What decision should this page support?

If the page does not support a decision, it becomes visual noise.

## Page Structure

A practical report page usually has:

- Key metrics at the top.
- Trends in the middle.
- Breakdown tables or charts below.
- Filters placed consistently.

## Visual Selection

- Use line charts for trends.
- Use bar charts for comparison.
- Use cards for key metrics.
- Use tables when exact values matter.
- Avoid pie charts when there are too many categories.

## Common Mistakes

- Too many visuals on one page.
- Using color without meaning.
- Showing metrics without context.
- Designing for beauty before clarity.
- Forgetting mobile or small-screen readability.
