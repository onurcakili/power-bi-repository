# Power BI Roadmap

Power BI is not only a visualization tool. A professional report depends on four connected skills:

1. Understanding the business question.
2. Preparing and modeling the data.
3. Writing correct DAX calculations.
4. Designing a report that helps people make decisions.

## Learning Flow

| Level | Focus | Outcome |
| --- | --- | --- |
| 101 | Power BI basics and report structure | Understand the workspace |
| 201 | Data modeling and relationships | Build reliable models |
| 301 | DAX and analytical calculations | Create reusable metrics |
| 401 | Publishing, governance, and performance | Prepare production-ready reports |

## Suggested Practice Project

Start with a sales dashboard because it naturally includes:

- Date table
- Product table
- Customer table
- Sales fact table
- Revenue, quantity, average order value, and trend metrics

This makes the project useful for learning both modeling and reporting.
